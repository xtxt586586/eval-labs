# Regression Comparison / 回归对比

Eval Labs 可在同一数据集和场景下比较两次评测运行，定位通过率变化、逐指标分数变化、新增失败、修复项和错误项。对比前需要保持数据集、场景及指标名称集合兼容。

## 可比较内容

- 通过率、失败数和错误数的变化。
- 每个指标的均值、通过率和分数差异。
- 逐样本状态：新增失败、已修复、持续失败、持续通过、新增错误及样本缺失。
- 任务创建时冻结的数据集、场景、指标 Prompt 和模型配置快照。

## 使用边界

回归比较反映两次运行结果的差异，不自动证明差异由单一配置变更导致。模型服务、提示词、数据内容、采样和运行环境都可能影响结果。应核对报告中的配置快照，并在相同样本与评分条件下解释变化。

Fixture Sandbox 是声明式工具结果回放，不运行任意 Agent 代码。LLM Judge 的校准结果只用于诊断，不构成评分准确性保证或 CI 自动发布门槛。
